# #7 不可变版本验收

2026-11-13，在集成分支 `integration/issues-3-7` 的正式 API 8000 / Web 8080 验证；使用真实 MySQL / Doris 探查得到的档案，不使用模拟源。

- [公开 HTTP](http.json)：当前候选门禁重新评估后冻结；并发重复冻结复用同一版本；五种制品下载原始字节与 SHA256 可重算。真实重探查、名称、时间、输入数组顺序不改变执行摘要，独立档案引用由制品包摘要绑定。
- 合法映射、质量规则及预算修订改变执行摘要和对应 Diff；旧修订与 PUT/PATCH/DELETE 被拒绝，已冻结原始字节保持相同。读取、下载、Diff、冻结均验证当前项目/租户范围与权限；撤权立即生效。事件保留版本/制品摘要引用，无已知秘密回显。
- [真实 Chrome](browser.json)、[界面](versions.png)：保存候选后从中文控制台冻结，复制 HOCON、实际下载、再次修订冻结、比较四段 Diff 均通过，无页面异常。Windows 剪贴板会将 LF 转换成 CRLF，归一换行后的文本与冻结制品一致；下载仍按原始字节精确重算 SHA256。
- [正式 API 重启](persistence.json)：重启并等待健康后，原冻结字节、事实、修订、档案引用及摘要全部保持相同。

范围为不可变手工审查制品；HOCON 标记 `review_only`，尚不运行引擎、模型、准备或发布。独立临时服务另行验证了当前白名单撤销会阻止复用旧门禁结果，见仓库中 #7 实现侧验收记录；正式环境白名单未为该测试修改。私有凭据、cookie 和完整请求状态仅保存在被忽略的运行目录。
